How the index is made

Every Monday the current C-GEM model (see methodology) prices each Indian credit type. The India Basket is the geometric mean of those prices, weighted by how many risk-adjusted credits each type supplies in India; issue 1 (9 Nov 2026) = 100. Removals, Avoidance and Nature-based use the same rule over their types. When the model version changes between issues, the change column says so, because part of the move is the model rather than the market. This is a model-based index from public data, not a traded price.
