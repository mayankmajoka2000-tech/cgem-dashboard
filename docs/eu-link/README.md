# EU link for India (working draft)

A one-page view of what Europe's carbon rules mean for India, prepared for C-GEM. It is not part of the dashboard yet.

- CBAM and India's CCTS: which sectors face both
- CBAM cost estimator (indicative only)
- EU carbon price since 2005, next to the range expected for India's CCTS credits
- 458 Indian CDM projects that asked to move to the Paris Agreement mechanism (Article 6.4)
- The EU carbon removal standard (CRCF)

Open `index.html` in a browser. With GitHub Pages turned on for the `docs` folder, it is served at
`https://mayankmajoka2000-tech.github.io/cgem-dashboard/eu-link/`.

Figures change: check the CBAM certificate price and the EU carbon price before quoting them.
